# Lab 6 — Section C: Dictionary Theory

## 1. Assignment, shallow copy and deep copy
- `copy_b = original` creates another reference to the same object. A mutation through either name is visible through the other.
- `original.copy()` creates a shallow copy. The outer dictionary is new, but nested mutable values such as lists and dictionaries are still shared.
- `copy.deepcopy(original)` recursively copies nested objects. It is appropriate when independent copies of nested data are required.

## 2. Dictionary access: d[key] and get()
- `d[key]` returns the value or raises `KeyError` when the key is absent.
- `d.get(key)` returns `None` when the key is absent.
- `d.get(key, default)` returns the supplied default when the key is absent. A frequency counter can use `counts[word] = counts.get(word, 0) + 1`.

## 3. setdefault()
`d.setdefault(key, default)` returns the current value if the key exists. Otherwise, it inserts the key with the default and returns that value. It is useful for grouping values into lists, for example `groups.setdefault(city, []).append(name)`.

## 4. Dictionary comprehensions
A dictionary comprehension constructs a dictionary from an iterable in one expression. Example: `{number: number ** 2 for number in range(1, 5)}` creates `{1: 1, 2: 4, 3: 9, 4: 16}`. It can also filter entries with an `if` clause.

## 5. Hashability and dictionary keys
Dictionary keys must be hashable. Immutable values such as strings, integers and suitable tuples can be keys. Lists and dictionaries are mutable and cannot be used as keys. Equal keys must have equal hashes; in Python, `1 == 1.0 == True`, so these values refer to the same key slot.

## 6. Safe mutation during iteration
Adding or deleting keys while directly iterating over a dictionary can raise `RuntimeError`. Iterate over a snapshot such as `for key in list(data):` or construct a filtered dictionary with a comprehension.

## 7. Average operation costs
Dictionary lookup, insertion and deletion are average-case O(1), assuming a well-distributed hash function. Iterating over all entries is O(n). Constructing a reverse index from all records is O(n) time and O(n) additional space; once built, a phone-to-contact lookup is average-case O(1).

## 8. Why nested dictionaries are useful
Nested dictionaries represent related fields under one identifier, such as `students[roll_no] = {"name": ..., "marks": {...}}`. They make record updates and reports convenient, while input validation is still needed to protect data consistency.
