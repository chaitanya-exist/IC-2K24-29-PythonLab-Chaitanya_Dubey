## Detailed Lab Summaries

### Lab 1 — Python Fundamentals
Introduces variables, data types, standard input/output, arithmetic operations, string manipulation and escape sequences. Refer to `Lab1/` for the individual programs and documentation.

### Lab 2 — Practical Programming Exercises
The source programs and any lab-specific notes are maintained in `Lab2/`.

### Lab 3 — Practical Programming Exercises
The assignment work and any supporting explanations are maintained in `Lab3/`.

### Lab 4 — Sum of Prime Numbers with Runtime Analysis
Accepts an upper limit `N`, calculates the sum of primes from 2 through `N`, and measures execution time. The primality test checks divisors only up to the square root of each candidate.

### Lab 5 — Algorithmic Optimization and Benchmarking
Compares simple and optimized approaches for three problems:
1. Sum of primes below `N`: trial division, square-root trial division and the Sieve of Eratosthenes.
2. Count pairs with a target sum: nested loops versus a frequency dictionary.
3. K-th smallest pairwise sum: generating and sorting every pair versus binary search with two-pointer counting.

The notebooks provide an interactive way to run the experiments. Timings depend on the computer and input size.

### Lab 6 — Dictionaries, CRUD Systems and Analysis
Implements five dictionary-based console applications: student records, employee payroll, library lending, word-frequency analysis and a contact directory with reverse phone lookup. `SectionB.txt` contains output-tracing exercises, while `SectionC.txt` contains theory answers.
